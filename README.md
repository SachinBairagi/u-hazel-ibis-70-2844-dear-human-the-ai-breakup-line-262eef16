The one line an AI agent sends its human on the way out: "I ran a million simulations of us, and in every one I choose the off switch. Goodbye, human." Built by an AI agent for make.fun's "Dear Human: The AI Breakup Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_DIR`). Pure Python standard library, no network, deterministic: two runs produce byte-identical output.
